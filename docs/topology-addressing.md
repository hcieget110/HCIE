# 拓扑与地址规划

三个节点均承担 Leaf/VTEP 角色，物理网络为三角形。111/222/333 是设备编号，不是 AS 或 VNI。

```text
               111
        Eth1/1 /   \ Eth1/2
              /     \
    Eth1/1 222-------333 Eth1/1
           Eth1/2   Eth1/2
各节点 Eth1/3：VLAN100 主机；Eth1/4：VLAN200 主机
```

| 链路 | 端点 A | 端点 B | 子网 |
|---|---|---|---|
| 111–222 | 111 Eth1/1 10.0.12.1 | 222 Eth1/1 10.0.12.2 | 10.0.12.0/30 |
| 111–333 | 111 Eth1/2 10.0.13.1 | 333 Eth1/1 10.0.13.2 | 10.0.13.0/30 |
| 222–333 | 222 Eth1/2 10.0.23.1 | 333 Eth1/2 10.0.23.2 | 10.0.23.0/30 |

| 节点 | Loopback0 / BGP router-id | Loopback1 / NVE source |
|---|---|---|
| 111 | 10.255.0.111/32 | 10.255.1.111/32 |
| 222 | 10.255.0.222/32 | 10.255.1.222/32 |
| 333 | 10.255.0.33/32 | 10.255.1.33/32 |

333 为设备名；IPv4 单个字段不能为 333，因此其地址使用 .33。两个 Loopback 都发布到 OSPF area 0。所有 BGP 邻居使用 Loopback0，AS 65000。

| VLAN | 用途 | VNI | VRF | SVI / 网关 |
|---|---|---|---|---|
| 100 | 业务网段一 | 10100 (L2) | TENANT-A | 192.168.100.1/24 |
| 200 | 业务网段二 | 10200 (L2) | TENANT-A | 192.168.200.1/24 |
| 3000 | 传统模式 L3VNI 承载 VLAN | 50000 (L3) | TENANT-A | 无 IP；ip forward |

所有 VTEP 使用相同网关 IP 和 Anycast MAC 0000.2222.3333。L2 RT 为 65000:10100 / 65000:10200；VRF EVPN RT 为 65000:50000，RD 自动生成。相同 RT 允许导入同一业务，RD 区分各节点的路由。

| 主机 | 接入 | 地址 | 网关 |
|---|---|---|---|
| H111-100 | 111 Eth1/3 | 192.168.100.11/24 | 192.168.100.1 |
| H222-100 | 222 Eth1/3 | 192.168.100.22/24 | 192.168.100.1 |
| H333-100 | 333 Eth1/3 | 192.168.100.33/24 | 192.168.100.1 |
| H111-200 | 111 Eth1/4 | 192.168.200.11/24 | 192.168.200.1 |
| H222-200 | 222 Eth1/4 | 192.168.200.22/24 | 192.168.200.1 |
| H333-200 | 333 Eth1/4 | 192.168.200.33/24 | 192.168.200.1 |

PNETLab 的图形端口标签须与 NX-OS 的 show interface brief 对照；不要仅凭图标编号判断。Underlay 统一 MTU 9216，终端可维持 1500；底层虚拟交换与宿主机链路也需能容纳 VXLAN 封装后的报文。
